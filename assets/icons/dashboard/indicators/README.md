# Dashboard Indicators

Drop custom indicator artwork in this folder for the dashboard designer.

Supported formats: SVG, PNG, JPG/JPEG, and WEBP.

Recommended filenames so the designer can automatically bind common vehicle signals:

- `left-turn.svg`
- `right-turn.svg`
- `headlights.svg`
- `high-beam.svg`
- `fog.svg`

Custom indicator files appear under the **INDICATORS** tab in FoxbodyDash Studio. Unknown filenames can still be used and their data source can be selected in the Properties panel.
